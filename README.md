# TMT — Time Management Tracker

Персональний планувальник тижневого графіка: часові блоки по категоріях (робота, навчання, відпочинок тощо), тижнева статистика виконання, встановлюваний offline-first PWA.

## Стек

- [Vite](https://vite.dev/) + [Vue 3](https://vuejs.org/) (`<script setup>`, Composition API) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/) — світла (м'ятна пастель) і темна (слейт/навy) теми, перемикання класом `dark` на `<html>`
- [`vite-plugin-pwa`](https://vite-pwa-org.netlify.app/) — installable, offline-first
- [`idb`](https://github.com/jakearchibald/idb) — типізована обгортка над IndexedDB
- [`@lucide/vue`](https://lucide.dev/) — іконки
